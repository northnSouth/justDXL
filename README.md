# JustDXL
A transport-agnostic packet handler for the DYNAMIXEL protocol used in DYNAMIXEL actuators made by ROBOTIS.

### Milestones
- [ ] Alpha release
- [ ] First documentation
- [ ] Ready-to-use driver for microcontrollers  
  - [ ] STM32 HAL
  - [ ] Arduino C++
  - [ ] Linux C
  - [ ] Linux C++
  - [ ] Linux Rust
